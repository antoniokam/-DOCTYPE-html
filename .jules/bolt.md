## 2026-03-31 - Optimize HTML tag stripping regex and function hoisting
**Learning:** In !DOCTYPE html.html, the isDataEmpty function was being recreated inside a recursive rendering loop (renderNodeData), causing unnecessary memory allocation and GC overhead. Additionally, the regex /<(.|\n)*?>/g used for stripping HTML tags was inefficient due to capture groups and alternation, making it significantly slower than a negated character class /<[^>]*>/g.
**Action:** Always hoist static regexes and pure helper functions to the global/module scope to prevent recompilation and recreation overhead during render loops. Use negated character classes like /<[^>]*>/g instead of alternation /<(.|\n)*?>/g for simple tag stripping to improve performance and prevent backtracking issues.
